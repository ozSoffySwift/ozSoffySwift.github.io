# ozSoffySwift.github.io

Root GitHub Pages site for Oz Soffy's apps.

- **`app-ads.txt`** — the AdMob authorized-sellers file. AdMob's crawler only reads
  `https://<host>/app-ads.txt` at the root of the developer website's host, which a project
  Pages site can't serve, so it lives here. Keep it identical to
  [`MeepleClock/docs/app-ads.txt`](https://github.com/ozSoffySwift/MeepleClock/blob/main/docs/app-ads.txt).
- **`index.html`** — redirects to the Meeple Clock site at
  [ozsoffyswift.github.io/MeepleClock](https://ozsoffyswift.github.io/MeepleClock/).
